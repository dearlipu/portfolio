# Saurav Panda Portfolio

This is a personal portfolio website for Saurav Panda built with Astro and Tailwind CSS.

## Features
- Clean personal portfolio layout
- Responsive design for desktop and mobile
- About, experience, education, and projects sections
- Contact links and GitHub profile link
- Professional, simple styling for personal branding

## Tech Stack
- Astro
- Tailwind CSS
- TypeScript

## Local Development

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

## Deployment
This project is set up for GitHub Pages deployment via the GitHub Actions workflow in `.github/workflows/deploy.yml`.
