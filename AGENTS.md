# Project Instructions

## General

- Do not change existing design unless explicitly requested.
- Preserve existing responsive behavior.
- Do not replace icons or images unless requested.
- Keep existing colors and typography unless requested.
- Reuse existing components before creating new ones.

## Before editing

- Inspect the relevant files first.
- Understand existing structure before making changes.
- Make the smallest necessary change.

## After editing

- Check for syntax errors.
- Check responsive behavior.
- Do not modify unrelated files.
- Summarize all changed files.
